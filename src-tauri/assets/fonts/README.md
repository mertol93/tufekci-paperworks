# Bundled Contents Font

`LiberationSans-Regular.ttf` is bundled so printed contents pages render consistently
and remain searchable across Windows, macOS, and Linux without relying on a system
font. It is an unmodified copy from the locked `pdfjs-dist` standard-font package.

The font is distributed under the SIL Open Font License 1.1. The complete copyright
notice and licence are retained in `LICENSE_LIBERATION.txt` beside the font file.
